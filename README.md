# 🍽️ نظام إدارة المطاعم المتكامل (Restaurant Management System)

نظام سحابي متكامل ومتقدم لإدارة المطاعم، صُمم لتسهيل وتنظيم كافة العمليات التشغيلية اليومية؛ بدءاً من نقاط البيع (POS) وإدارة الطاولات، ووصولاً إلى تتبع المخزون وحساب تكاليف وجبات الطعام بدقة والرقابة المالية والصلاحيات.

---

## 🌟 الميزات الرئيسية للنظام

### 1. 🛒 نقطة البيع السريعة (POS)
- واجهة بيع تفاعلية وسريعة تدعم شاشات اللمس.
- إدارة طلبات الصالة (Dine-in)، السفري (Takeaway)، والتوصيل (Delivery).
- إصدار وطباعة الفواتير والإيصالات الحرارية، مع دعم تفاصيل الورديات.

### 2. 🍲 تحضير الوصفات وحساب التكاليف الذكي (Smart Recipe Costing)
- ربط أصناف قائمة الطعام بالمواد الخام في المخزون.
- احتساب تكلفة تحضير الوجبة تلقائياً بناءً على تكلفة المواد الخام.
- أداة تسعير سريعة واقتراح هوامش الربح (+30%، +50%، إلخ) مع اعتماد سعر الوجبة فورياً.

### 3. 📦 إدارة المخزون والمستودعات
- تتبع أرصدة المواد الخام ومكونات الأطعمة والمنتجات الجاهزة.
- تنبيهات انخفاض المخزون وإدارة الموردين وحركات الشراء والتوريد.

### 4. 🪑 إدارة الصالة والطاولات والحجوزات
- تخطيط ومتابعة حالة الطاولات لحظياً (شاغرة، مشغولة، محجوزة).
- نظام متكامل لحجز الطاولات المسبق للزبائن والمناسبات.

### 5. 💰 الإدارة المالية والخزينة والمصروفات
- تتبع حركات السيولة النقدية، الإيداع، والسحب من الخزينة.
- تسجيل وتبويب المصروفات التشغيلية اليومية والشهرية.
- إدارة رواتب الموظفين والسلف المالية بدقة.

### 6. 🔐 إدارة المستخدمين ومصفوفة الصلاحيات (Role-Based Access Control)
- نظام صلاحيات محكم وديناميكي يتيح تقييد أو منح الوصول لأي قسم لكل موظف.
- مصفوفة صلاحيات تفاعلية (Permissions Matrix) للتحكم السريع.
- تخصيص روابط القائمة الجانبية وإخفاء الأقسام غير المصرح بها تلقائياً.

## 🛠️ البنية التقنية (Tech Stack)

### 🔹 الواجهة الأمامية (Frontend)
- **Framework:** [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State Management:** Zustand
- **API Client:** Axios

### 🔹 الواجهة الخلفية (Backend)
- **Framework:** [Django](https://www.djangoproject.com/)
- **API Engine:** [Django Ninja](https://django-ninja.dev/) & Ninja Extra
- **Authentication:** Django Ninja JWT
- **Database:** SQLite / PostgreSQL
- **Language:** Python 3.13+
