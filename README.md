# 🍽️ نظام إدارة المطاعم المتكامل الذكي (Restaurants11 System)

نظام سحابي متكامل ومتقدم لإدارة المطاعم ونقاط البيع والمخازن، مدعوم بتقنيات **الذكاء الاصطناعي (AI)** والبصمة البيومترية المادية، ومبني بأحدث معايير الأداء والسرعة باستخدام **Next.js (App Router)** و **Django Ninja**.

---

## 🌟 الميزات الرئيسية للنظام

### 1. 🛒 نقطة البيع السريعة (POS)
- واجهة بيع تفاعلية وسريعة وفائقة الاستجابة تدعم شاشات اللمس والأجهزة اللوحية.
- إدارة طلبات الصالة (Dine-in)، السفري (Takeaway)، والتوصيل (Delivery).
- إصدار وطباعة الفواتير والإيصالات الحرارية، مع دعم تفاصيل الورديات (Shifts) والخزينة اللحظية.
- اعتماد العملة بالدينار الليبي (`د.ل`) في كافة المعاملات والحسابات.

### 2. 📦 إدارة المشتريات والتوريد الآلي وحساب التكاليف (Procurement & Costing)
- **دليل الموردين (Suppliers Directory):** إدارة شاملة لبيانات الموردين والشركات، وتتبع الأرصدة والمستحقات الآجلة والمدفوعات النقدية.
- **فواتير التوريد والمشتريات (Purchase Invoices):** تسجيل الفواتير الورقية والمواد الخام المشتراة وترحيلها لحظياً إلى المخزن.
- **محرك التكلفة الآلي (Automated Weighted Average Cost):** احتساب متوسط تكلفة الوحدة للمواد الخام تلقائياً ومعادلة المخزون بدون أي تدخل بشري فور تأكيد استلام الفاتورة.
- **إدارة الرصيد الافتتاحي:** إمكانية تحديد سعر وتكلفة رصيد أول المدة عند تأسيس المخزن.
- **شاشة عرض الفواتير وطباعتها:** سجل كامل لعمليات التوريد مع مؤشرات أداء مالية (KPIs) ومعاينة الفاتورة وطباعتها.

### 3. 🍲 تحضير الوصفات وحساب التكاليف الذكي (Smart Recipe Costing)
- ربط أصناف قائمة الطعام بالمواد الخام في المخزون بدقة متناهية.
- احتساب تكلفة تحضير الوجبة تلقائياً بناءً على متوسط تكلفة المواد الخام الحالية في المخزن.
- أداة تسعير سريعة واقتراح هوامش الربح (+30%، +50%، إلخ) مع اعتماد سعر الوجبة فورياً.
- الخصم التلقائي للمكونات من رصيد المخزن فور بيع أي وجبة في نقطة البيع.

### 4. 👆 نظام الحضور والانصراف بالبصمة البيومترية والذكاء الاصطناعي (AI Biometric Attendance)
- **معالجة الصور المتقدمة (OpenCV & CLAHE):** تنقية صور البصمات، توحيد المقاس إلى 128x128، وتطبيق تقنية *Contrast Limited Adaptive Histogram Equalization* لتعزيز تباين خطوط التلال والأخاديد وإزالة تشويش الغبار والرطوبة.
- **شبكة استخراج الميزات (TensorFlow CNN):** تحويل صورة البصمة إلى متجه رقمي عالي الدقة (128-dimensional embedding vector).
- **المطابقة الآنية (Cosine Similarity):** مقارنة المتجه الممسوح ببصمات الموظفين المسجلة وتسجيل الحضور والانصراف فور تجاوز نسبة التطابق للحد المعتمد.
- **جسر الربط مع أجهزة البصمة المادية (`hardware_scanner_bridge.py`):** دعم مباشر لقارئات البصمة المكتبية بنظام USB (ZKTeco ZK4500, ZK7500, ZK9500) عبر مكتبة `pyzkfp`، والمستشعرات الضوئية التسلسلية (AS608, R307, R503) عبر منافذ COM التسلسلية ومكتبة `pyserial`.
- **دعم نماذج TFLite:** إمكانية تشغيل نموذج الاستدلال عبر `tflite-runtime` باستهلاك ذاكرة ضئيل وسرعة استجابة فائقة على الأجهزة الطرفية وRaspberry Pi.

### 5. 🪑 إدارة الصالة والطاولات والحجوزات
- تخطيط الصالة ومتابعة حالة الطاولات لحظياً (شاغرة، مشغولة، محجوزة).
- نظام متكامل لحجز الطاولات المسبق للزبائن والمناسبات وربط الحجز بالطلبات.
- إضافة الطاولات وتعديل سعتها ومواقعها بسهولة ومرونة.

### 6. 💰 الإدارة المالية والخزينة والمصروفات والرواتب
- تتبع حركات السيولة النقدية، الإيداع، والسحب من الخزينة الرئيسية وتتبع رصيد الصندوق.
- تسجيل وتبويب المصروفات التشغيلية اليومية والشهرية وتحديد جهات الصرف.
- إدارة رواتب الموظفين والسلف المالية وحساب صافي المستحقات.

### 7. 🔐 إدارة المستخدمين ومصفوفة الصلاحيات (Role-Based Access Control)
- نظام صلاحيات محكم وديناميكي يتيح تقييد أو منح الوصول لأي قسم لكل موظف (مدير، كاشير، نادل، طاهٍ).
- مصفوفة صلاحيات تفاعلية (Permissions Matrix) للتحكم السريع في الواجهة.
- تخصيص روابط القائمة الجانبية وإخفاء الأقسام غير المصرح بها تلقائياً.
- دعم تسجيل الدخول باسم المستخدم أو البريد الإلكتروني مع معالجة آمنة لبيانات الاعتماد.

### 8. 🎨 الواجهة العصرية والتصميم المتجاوب
- تصميم أنيق وعصري يدعم الوضعين الداكن والفاتح (Dark & Light Theme).
- دعم كامل للغة العربية واتجاه الكتابة من اليمين لليسار (RTL).
- حواف مضيئة وتأثيرات بصرية جذابة لبطاقات المنتجات والمكونات.

## 🛠️ البنية التقنية (Tech Stack)

### 🔹 الواجهة الأمامية (Frontend)
- **Framework:** [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (مع دعم مخصص لـ Dark Mode)
- **Icons:** Lucide React
- **State Management:** Zustand
- **API Client:** Axios (مع دعم التوكن التلقائي عبر Interceptors)

### 🔹 الواجهة الخلفية (Backend)
- **Framework:** [Django](https://www.djangoproject.com/)
- **API Engine:** [Django Ninja](https://django-ninja.dev/) & Ninja Extra
- **Authentication:** Django Ninja JWT (JSON Web Tokens)
- **Computer Vision & AI:** OpenCV (`opencv-python-headless`)، TensorFlow، Keras، TensorFlow Lite، NumPy
- **Hardware Integration:** pyzkfp (ZKTeco USB SDK)، pyserial (Serial COM UART)
- **Database:** SQLite (بيئة التطوير) / PostgreSQL (الإنتاج)
- **Language:** Python 3.13+

## 🚀 طريقة التشغيل والتثبيت (Quick Start)

### 1. إعداد وتشغيل الواجهة الخلفية (Django Backend):
```bash
# الانتقال لمجلد الواجهة الخلفية
cd restaurantsApi

# إنشاء وتفعيل البيئة الافتراضية
python -m venv .venv

# نظام Windows:
.venv\Scripts\activate
# نظام Linux / macOS:
source .venv/bin/activate

# تثبيت الحزم المطلوبة
pip install -r requirements.txt

# تطبيق ترحيلات قاعدة البيانات
python manage.py migrate

# تشغيل خادم التطوير
python manage.py runserver 127.0.0.1:8000
```
- رابط الخادم: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- واجهة توثيق الـ API التفاعلية (Swagger UI): [http://127.0.0.1:8000/api/docs](http://127.0.0.1:8000/api/docs)

---

### 2. إعداد وتشغيل الواجهة الأمامية (Next.js Frontend):
```bash
# الانتقال لمجلد الواجهة الأمامية
cd restaurant-frontend

# تثبيت الحزم والتبعيات
npm install

# تشغيل خادم التطوير
npm run dev
```
- رابط التطبيق في المتصفح: [http://localhost:3000/](http://localhost:3000/)

---

### 3. تشغيل جسر أجهزة البصمة المادية (Hardware Scanner Bridge):
لتوصيل ماسح البصمة المكتبي واستقبال حركات الحضور والانصراف اللحظية:
```bash
cd restaurantsApi

# تفعيل البيئة الافتراضية أولاً
.venv\Scripts\activate

# تشغيل الماسح المكتبي بنظام USB (ZKTeco):
python employees/services/hardware_scanner_bridge.py --mode zkteco

# أو تشغيل مستشعر بصمة ضوئي تسلسلي (Serial / COM):
python employees/services/hardware_scanner_bridge.py --mode serial --port COM3

# أو اختبار النظام عبر محاكاة صورة بصمة:
python employees/services/hardware_scanner_bridge.py --mode test --image path/to/sample_fingerprint.png
```
